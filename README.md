# Music AI Schema

Classify music AI tools with a shared schema. Website: https://privatenobo.github.io/test-repo/

## How it works

- Each tool is one JSON file in `tools/`.
- `data/schema.json` defines the allowed values.
- Anyone can propose a tool or a change as a pull request, using the form on the website or by adding a file by hand.
- A check runs automatically on every pull request and reports format errors.
- After a pull request is merged, the website updates automatically.
