Music AI Schema

An open project to classify current music AI tools by their properties. Anyone can contribute.

how it works

v0.2

Schema
Each tool is described by its input, its output and other features. A tool with several functions gets one mode per function.
Browse
Click properties in the schema to filter the tools.
Contribute
Classify a tool and submit it on GitHub. It is added to the list after review.
contributegithub

Submit on GitHub

Requires a free GitHub account. Your GitHub username is shown publicly on the issue.
