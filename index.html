Music AI Schema

An open project to classify current music AI tools by their properties. Anyone can contribute.

how it works

v0.2

Schema
Each tool is described by its input, its output and other features. A tool with several functions gets one mode per function.
Browse
Click properties in the schema to filter the tools.
Contribute
Each tool is one JSON file. Add or change one through a pull request, with the form or as text. An automatic check validates it. After the merge, this site updates.
contributepull request

Prefer text? Add a JSON file to tools/ on GitHub. Format and rules: README.

Submit as pull request

On GitHub: Commit or Propose changes, then Create pull request. Requires a free GitHub account; your username is shown publicly.
